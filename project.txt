# TaskFlow - Full Build Plan

## What This Project Is

Distributed workflow orchestration engine. Temporal clone.
Event-sourced DAG executor with Redis workers, durable timers, signals,
parent/child workflows, leader election.

Not a todo app.

Positioning: "Temporal-lite you can self-host on one JVM."

Stack:
- Backend: Java 21 / Spring Boot 4 / JPA / PostgreSQL / Redis
- Frontend: Next.js / TypeScript / TanStack Query / React Flow
- Infra: Docker Compose (Postgres + Redis + app), GitHub Actions CI

## 2. Instance Detail Page - The 10/10 Moment

Recruiters screenshot this page. It needs:

Header: workflow name | status badge | instance ID | started | duration

Tabs:
- Timeline   - vertical DAG with step nodes colored by status (done/failed/running/pending)
- Events     - append-only log, filter by type, expand JSON payloads
- Context    - current step input/output, full accumulated state
- Signals    - incoming + pending, send button
- Timers     - scheduled + fired + cancelled
- History    - replay event log with "replay from here" button
- Logs       - stdout/stderr from step handlers

Unique features no CRUD todo app has:
- Replay from sequence N (Temporal signature feature)
- Show event log as source of truth, not just current state
- Visual DAG with live status

Currently only 2 exist:
- POST /api/workflow/start/{name}
- POST /api/workflow/{id}/signal/{signalName}

Need to add:

```
GET    /api/workflow/instances                  list + filter (status, name, date)
GET    /api/workflow/instances/{id}             full state + current step
GET    /api/workflow/instances/{id}/events      paginated event log
GET    /api/workflow/instances/{id}/context     accumulated step outputs
POST   /api/workflow/instances/{id}/cancel      terminate
POST   /api/workflow/instances/{id}/replay/{seq}  rebuild state from sequence
GET    /api/workflow/instances/{id}/timers      active + history
GET    /api/workflow/instances/{id}/signals     pending signals
GET    /api/workflows                            registered workflow types
GET    /api/workflows/{name}                    schema + input schema + DAG
GET    /api/admin/leader                        current leader + epoch
GET    /api/admin/workers                       consumer group state
GET    /api/admin/queues                        redis stream stats
GET    /api/health                              liveness
GET    /api/metrics                             prometheus
```

## 6. CI/CD

GitHub Actions:

`.github/workflows/ci.yml` - runs on PR + push to main
  jobs:
    - lint (mvn checkstyle or spotless for backend, eslint for frontend)
    - typecheck (tsc --noEmit for frontend, mvn compile for backend)
    - test-unit (mvn test -Dgroups=unit for backend, jest for frontend)
    - test-integration (mvn test -Dgroups=integration with Postgres service)
    - build (mvn package, next build)

`.github/workflows/deploy.yml` - runs on tag v*
  jobs:
    - build-image (Docker multi-stage)
    - push (ghcr.io)
    - deploy (fly.io or render)

Branch protection on main:
- require CI green before merge
- require 1 review
